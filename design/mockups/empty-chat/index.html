Empty agent chat

The New chat picker stays as it is. A chat with nothing in it is where you pick one up: it lists what this CLI already has, from the CLI's own store. This round adds a filter to the list, drops folders you cannot resume in, and tries a horizontal effort slider under a shorter model list.

1. A filter, and only folders you can resume in

Left out for good: folders that no longer exist, since a chat cannot be resumed there. That covers temp dirs, deleted worktrees and chats that ran on another machine, which is where the repeated names came from. Left out of the list, kept in the filter: scratch folders, meaning anything under the temp dir, ~/Library or a dot folder. Every folder row shows its parent path, so two folders with one name can be told apart. The list scrolls in its own space and never runs under the composer.

2. The model picker, effort along the bottom

The list is the first five the CLI offers, which is its default plus the current generation. More models adds the rest to the same list, which then scrolls, and an older model you have picked stays as a sixth row when the list is short again. Effort is one fat horizontal slider with a dot per stop. Default is the first stop, drawn as a ring with no fill, because the CLI does not say which level it stands for. Live: click, drag, open More models.
