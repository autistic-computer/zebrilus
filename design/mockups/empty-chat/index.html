Empty agent chat

The New chat picker stays as it is. A chat with nothing in it is where you pick one up, from the CLI's own store. It shows the welcome and two buttons: one for the folder the next chat starts in, one to resume a chat the CLI already has. The model picker is one list that scrolls.

1. Two buttons: where, and what to pick up

The empty chat shows the welcome and two buttons. The first names the folder the next message goes to; its menu is a plain picker, and picking a folder moves this empty chat there, so the button and the pane title change. Resume lists chats to pick up: the ones in that folder first, then the newest from other folders, and its search looks through every chat the CLI has. No nested menu, so nothing leaves the pane. Left out as before: folders that no longer exist never show, and scratch folders (temp dir, ~/Library, dot folders) only show when a search matches them.

2. The model picker, effort along the bottom

Every model the CLI offers, in its order, in one list six rows tall that scrolls. When it opens, the current model is scrolled into view. The button names the model by its display name. Effort is one fat horizontal slider with a dot per stop. Default is the first stop, drawn as a ring with no fill, because the CLI does not say which level it stands for. Live: click, drag, scroll the list.
