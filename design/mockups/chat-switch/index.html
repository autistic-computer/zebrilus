Chat switch: another chat, another folder, the CLI

Once a chat has a message, the folder and Resume buttons of the empty chat are gone, and nothing takes the chat to the agent's own CLI. Three takes on one live Claude Code chat in ~/dev/zebrilus. Each answers both: pick another chat or folder, and jump to the CLI and back.

Take 4 · Icons on the right

Two icon buttons before the pane's own split and close buttons. The clock opens the chats and folders menu. The terminal flips the pane to the CLI, and on the CLI a chat icon in the same spot flips it back. The flip button is the one the header had until 2026-11-08: flip-agent, its busy choices (now, or when idle) and finding the session the CLI is on are all still in the tree.

Take 1 · The title is the menu

The pane title already names the agent and the folder. It gets a chevron and opens one menu: this folder's chats, the other folders, a new chat, the folder picker, and the CLI. The terminal's title carries the way back.

Take 2 · Back and a switch

Two controls in the pane header. A back chevron returns to the ready screen, the one with the folder and Resume buttons. A two-way switch flips the same pane between the chat and the CLI, and shows which one you are in.

Take 3 · Slash commands

No new chrome. /resume, /new, /cd and /cli join the composer's command menu and list in the surface the @ menu uses. The CLI has no composer, so the way back is a palette command.

What the jump does, in every take

  • Same pane. The chat pane turns into a terminal in place, in the chat's folder, running claude --resume <id> (codex resume <id> for Codex). select-pane-kind terminal does this today; the layout, window and title stay.
  • One owner. zz's own driver for the chat stops before the CLI starts, so two processes never write one session. While a turn runs, the flip asks: now, or when idle.
  • Back. The terminal turns into a chat again on the session the CLI is on, even after a clear or a resume inside it: flip-agent already finds that session.
  • No messages yet. A chat that never sent anything has no session in the CLI, so the jump opens the plain CLI in that folder.
  • Another chat. Picking one swaps the session inside the pane, the way Resume on the empty chat does. The chat you leave stays in the CLI's store and is the first row next time.
