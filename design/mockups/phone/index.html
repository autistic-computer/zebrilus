Phone app

The iPhone shell's main views in the order a new user meets them, redrawn to catch up with the desktop. The phone is built around chats now, the way the desktop sidebar is, and it uses the desktop's word Machines for hosts. Where a view exists today it keeps its structure: one pane per screen, the floating pill at the bottom, the bento overview, sheets for actions. Each caption says what the view is for and what changed. Switch theme and mode in the corner. Three takes on the sheet itself: Sheets. Three takes on showing each pane's program: Program icons.

1. First run, no machine saved

Today the app opens on one row and nothing that says what zz is or where its computers are. Three takes on a first screen: the desktop's Machines page, a welcome, and a screen where you just type where to connect.

2. Getting in

Adding a machine, signing in to it, and the Machines page once a few are saved. Today signing in is a centered dialog; here every step is a sheet in the lower half, where the thumb is.

3. A machine

Inside a machine the phone opens on its chats, the way the desktop's chat view does, and terminals and browsers come after. A pane still fills the screen with the pill at the bottom. The agent chat, its composer and its asks are zz-ui's, the same as the desktop's.

4. Getting around

The overview and the pill menu stay the phone's navigator. The pill menu now starts things the way the desktop does, chat first. Settings lists every page the desktop has.
