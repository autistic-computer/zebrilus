Machines tiles

Today each machine is a square tile holding two terminal minis too small to read, and a failed machine spends a whole tile on one cut-off error. Five takes, each drawn on two days. Today is what the simulator shows: zzios-zebrilus up, Local socket and wsl-archlinux failed. Busy has five machines: a chat on the macbook waits on you, alienware is building, win-desktop is off. A and D drop the previews. B and E keep them, but cropped to a size you can read, and tapping one takes you to that pane. C shows the sessions where the previews were.

A. Rows

No previews. Each machine is one row, like Settings: the OS mark with the status dot, the name, one line under it. Needs you first, not connected last. Tap opens the machine; on a failed one it retries.

B. Pick up

One preview, big enough to read: the pane you were last on, from any machine, or the one waiting on you. Tapping it goes straight into that pane. Every machine below it is a row, as in A.

C. Sessions

No previews; each connected machine lists its sessions, one line each: the name, a glyph per window, and waiting or working on the right. Tapping a session goes straight into it, skipping the machine page. Machines that are not connected collapse to rows at the bottom.

D. Small tiles

Keeps the grid, drops the previews, so tiles shrink to about a third of today's height. Each holds the OS mark, the name and a glyph per window. A tile waiting on you is tinted; a failed one says Failed and keeps its error for the tap.

E. Window shelf

Previews stay, one per window, and a tap goes to that window. They are crops, not shrinks: the bottom-left of the window at about 60%, where the prompt and the newest output are, so the text stays readable. A two-pane window gets a wider card. Each machine's row of windows scrolls sideways; not connected machines are rows at the bottom.
