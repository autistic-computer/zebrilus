Pip transitions

What a pip does when it opens out of the thing you clicked. Click the subagent row, the code block or the diagram in any window. Click it again, or the pip's close button, to send it back. Scroll the source out of view before closing to see what happens when there is nowhere to return to.

Speed Spring

What the app can draw

  • Frame, corners, fade, clip: all three sources, both directions. The frame already moves on four springs, one per edge.
  • Scaling: only images and diagrams. Live text cannot zoom, so in B the title and the code lines travel at their own size.
  • Closing: the pane is gone the moment it closes, so the way back is drawn with the pip's frame and header only, or with the picture for a diagram. A subagent's chat and a code view fade out first.
  • No way back: when the source has scrolled away, the pip shrinks a little in place and fades, 160ms.
