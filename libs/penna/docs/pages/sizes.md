# Sizes

One ladder of control sizes. Each step sets height, text, horizontal inset, icon size and icon gap together.

Small and xsmall fit dense chrome. Large and xlarge highlight one main action. Touch (44) is the minimum finger target; touch-large (56) carries phone main actions and fields (see [Phone](phone.html)). Fields use a tighter horizontal inset than buttons because text starts at the edge.

| Size | Height | Text | Button / field inset | Icon / gap |
| --- | --- | --- | --- | --- |
| `Size::XSmall` | `20` | `caption` | `8` / `6` | `12` / `4` |
| `Size::Small` | `24` | `small` | `8` / `6` | `12` / `4` |
| `Size::Medium` | `28` | `body` | `12` / `8` | `14` / `6` |
| `Size::Large` | `32` | `body` | `16` / `10` | `16` / `6` |
| `Size::XLarge` | `40` | `lead` | `16` / `12` | `16` / `8` |
| `Size::Touch` | `44` | `touch-body` | `16` / `12` | `16` / `8` |
| `Size::TouchLarge` | `56` | `touch-body` | `16` / `12` | `20` / `8` |

## In a line of text

Keycaps and badges take the line height of the text they sit in — 16 in `small`, 18 in `body` — so a line never grows. Icons beside text step with the type size: 12 beside `small`, 14 beside `body`, 16 beside `lead` and `heading`.
