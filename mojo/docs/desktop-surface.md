# Configured native surface decisions

The actual desktop terminal, sidebar and browser binding builders delegate to `zz_client::desktop_surface`. The extracted enums retain each builder's supported actions, including terminal font bindings that install NoAction, browser ClosePane, and every indexed browser-tab identity. Bindings from another action family remain ignored by that builder. `desktop_native_bindings` provides the same classification in Mojo. This is classification of actual emitted bindings; it does not replace the framework's chord matcher or installation history.

The actual terminal key handler delegates its admitted key decision to `terminal_chrome_key_action`. Font adjustment precedes a swallowed overlay key. Swallow precedes Find; Find precedes refocusing an already open search; copy, select-all, clear-history and paste follow. Clear-history in command output consumes the key without sending an action. The original early return for an open search whose terminal focus is elsewhere, cursor reset, text-input tracking, raw Control-V image handling and subsequent raw forwarding remain at their actual source call sites. Mojo preserves a separate native result and no-effect consumed result. This decision helper alone does not activate an application keyboard hook.

The actual MuxClient font handlers delegate the one-point adjustment, 1–256 point clamp, Float32 epsilon guard and retained offset arithmetic to the same source module. `desktop_terminal.TerminalFontState` ports the adjustment and configuration-reload state. It preserves the accepted delta when changing the local offset and recomputes the retained offset after a clamped reload. The evidence compares finite Float32 bits, including signed zero, adjacent representable values and subnormal inputs; it adds no theorem about arbitrary invalid appearance payloads.

Run `python3 mojo/scripts/desktop_surface_vectors.py` for 4,496 actual terminal decisions, all 561 typed actions in each of the three native contexts, 396 exact adjustment/offset cases and 4,096 configuration/adjustment trace steps. The actual source results occupy 99,120 bytes. The final source/Mojo differential peaked at 214 MiB, scoped source clippy at 375 MiB, and the actual desktop crate check at 834 MiB. Its only warning is the existing platform-unused traffic-light helper.

Complete configured context routing still needs the actual framework's key identity, character-alternative matching and binding installation history. Its append-only bindings can retain an older native callback when a later cross-family rebind emits no replacement. Removed supported chords install NoAction. The live adapter must preserve those rules and must not fall back to stock shortcut planners after an unbound or unsupported configured lookup. Browser controller and host effects are a separate port; sidebar and terminal UI consumers remain to connect after their state and queue admission checks.
