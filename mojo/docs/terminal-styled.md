`terminal_styled_fixture` renders the actual native terminal `RowRenderCache` through its GPU, using an isolated font system loaded from explicitly listed files. The separate Mojo probe reads the resulting cells, packed styles, grapheme dictionary, overlays, cursor, appearance, and font manifest. Its four explicit font slots deliberately remain distinct even when they reference the same regular face. The existing terminal pixel baseline is unchanged.

Run `python3 scripts/terminal_styled_pixels.py --record --scale 1` from `mojo` to capture the comparison under the shared 4 GiB guard. The script writes native and Mojo PNGs, an amplified difference, source scene geometry, candidate glyph bounds, seven exact metric bit patterns, resolved native font diagnostics, and a JSON report under `target/port/terminal-styled-reference`. Without `--record`, any differing pixel or metric fails the check. `--native-only` captures the source without compiling the Mojo UI. Cases and scales can be selected individually.

The first Linux run at 13 logical pixels and device scale 1 matched every pixel and metric in four font cases: regular-only, all real style faces, regular plus bold with missing italic, and synthesis disabled. Those 245,760 pixels cover ordinary and selected regular, bold, italic, and bold-italic text, including ligatures. The isolated fonts are JetBrains Mono Regular and the four installed DejaVu Sans Mono faces.

The native font-option diagnostics request synthesis when a styled request resolves to the same native face as its same-family request with that style removed. The Linux native rasterizer currently ignores those synthetic bold/italic and font-smoothing hints; its actual pixels remain unchanged. The macOS rasterizer consumes them. The Linux equality above therefore does not establish synthetic-style parity on macOS, nor justify enabling synthetic outlines on Linux merely from the diagnostic flags.

The initial additional captures exposed 2,005 differing pixels for each packed-decoration and contrast case, 2,305 for multilingual glyphs, and 1,480 for IME composition. All seven metric bit patterns agree. These are recorded failures, not accepted tolerances. The source custom-draws a specific light-box and solid-block set; other box characters and shades use the font. Its scalar batches align each source cluster to its cell, while dictionary graphemes shape separately with natural internal advances. Explicit fallback files cover Greek, Cyrillic, Hebrew, Arabic, Devanagari, Thai and CJK; the fixture also includes combining marks, wide cells and both spacer forms. The decoration cases include faint, invisible, strike, overline, hyperlink, five underline styles, resolved inverse colors, selected foreground and low contrast. IME is checked over an existing selection.
