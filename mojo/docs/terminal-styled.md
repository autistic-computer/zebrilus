These open failures require two separate source contracts. `ala/crates/ala/src/bounds_tree.rs` assigns an order equal to the maximum intersecting order plus one. `Scene` preserves explicit text layers, then merges primitives by `(order, PrimitiveKind)`; underlines precede monochrome glyphs within one order. In the recorded graphics scene, overlapping connector quads deepen one row's order, so a later text row can render before an earlier row's underline. `text_system/line.rs` uses actual shaped-line bounds for these layers. The current row replay does not implement this global scene planner, and insertion order or a fixed per-row sort cannot establish equivalence.

Rounded and diagonal connectors use `PathBuilder::stroke` with the source tessellator's default stroke options. The rounded control fraction is 0.25; diagonals deliberately extend beyond their cell bounds. The resulting triangles carry constant path coordinates `(0, 1)`, so the source path fragment produces full triangle coverage and edge antialiasing comes from the renderer's multisampled intermediate target. `ala-platform/src/wgpu/wgpu_renderer.rs` selects the highest supported path sample count from 4, 2 and 1, resolves the RGBA path target, then composites its sprite. A cell-clipped scalar mask neither preserves that resolve/composite boundary nor its overhang. These source path and global-order contracts remain explicit work for the shared renderer rather than an accepted pixel tolerance.
