Retained listing state has a 16 MiB conservative byte budget. Overflow clears rows/root/marks, produces a terminal error and returns a captured-source cancellation command. Rejection occurs before partial mutation. Each worker/UI mailbox is separately bounded to 16 MiB and 4,096 events, and a connection has at most 64 pending path requests. Mailbox overflow reports a connection error and closes the socket, canceling its native work; the UI receives a picker-close notification. A 50,000-entry retained listing, source-stale completions, exact counter wrap, duplicate cancellation, request-count overflow and atomic mailbox append/merge refusals pass focused probes.
