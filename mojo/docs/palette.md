# Palette model

The local palette opens in the source places/actions mode. The initial attached-host chip is automatic. A leading colon selects raw commands without dropping the place chips. Enter activates places or fills a verb slot; Tab enters a place. Empty-field Backspace discards a filled slot and clears the field; an automatically filled target discards the draft. Shift-Tab can return a popped chip for highlighting in its parent list.

`PaletteFleet` retains the host/session/window/pane hierarchy independently of terminal cell planes. `palette_candidates`, `palette_children`, and `search_places` preserve native scope, numeric query, offline-host, fuzzy-score, recency-boost and stable-tie rules. Written places use the actual `@host:%pane`, `@host:@window`, `@host:$session` and path/line suffix grammar.

`palette_verbs` retains curated actions, the command catalog, GUI offers and aliases in source order. Its alias tokenizer is the native completion tokenizer, including its partial quote behavior. Open alias slots are inferred by the actual option parser contract. `compile_palette_verb` preserves structured arguments when the source can do so, and returns command text otherwise. Raw execution uses `if-shell -F 1 <line>` so the daemon parses commands in its own context.

`PaletteController` owns query/cursor, chips, draft values and labels, selected row, navigation engagement, finishing state and the twenty-command transient history. Its effects request execution, activation, connection, notification or an external GUI/file level. Activation closes only after the host adapter reports success. `PaletteModel` builds local rows from the fleet and explicit `PaletteDecorations`; those decorations keep presentation metadata distinct from retained terminal content.

`PaletteRow` exposes label, detail, right text, UTF-8 match ranges, muted byte prefix, status, running state, icon name, indentation, expansion and an optional typed shortcut. Action tags are 0 header, 1 place, 2 verb, 3 command, 4 history, 5 target-slot fill and 6 text-slot submission. Pill kinds match the native Mode, Status, Code, Crumb and Action variants. Status values are Online 0, Running 1, Waiting 2 and Offline 3.

The local workspace adapter activates the rendered component through the native key and ordered input controllers. Agent chat summaries, decayed/persisted recents, argument completion and GUI/file levels still require host services. Snapshot projection and private daemon controller execution are also exercised directly. Typed daemon prompt and chooser state is already available separately through `AppModel.dialogs`.

The place differential compares 9,067 cases and 91,463 bytes against actual `zz-client` helpers. The verb differential compares 12,331 cases and 4,410,156 bytes against actual `zz-client` verbs and completion. The controller probe checks source-derived transitions and exact limits. The presentation differential compares 2,890 cases and 1,524,161 exact bytes. The presentation oracle calls the real `UnifiedPalette.rebuild_places`, retaining actual row, pill, placeholder, action and initial-selection outputs rather than a second implementation of its rules.

Interactive input follows the native 64 KiB limit. Pure search/tokenizer helpers accept at most 1 MiB of query or alias text. Fleets accept 65,536 hierarchy nodes and 16 MiB of text; the exact next-node/next-byte rejection is tested. Alias tokenization accepts 4,096 words, and presentation rows are capped at 65,536 with 16 MiB of aggregate text. A repeated 1 MiB ancestor-label regression verifies rejection while building the needs-you rows. GUI offers also have a 16 MiB aggregate text limit. These extra adapter refusals are explicit resource limits.

Target and GUI metadata are generated from source by the corresponding vector script with `--generate`; ordinary checks reject stale generated metadata. Reference artifacts and exact output reports are written under `target/port`.

Shortcuts retain the source Keys-versus-Text distinction. A missing shortcut is distinct from Text with an empty value. Keystrokes preserve `key`, optional `key_char`, and Shift/Ctrl/Alt/Platform/Function bits 1/2/4/8/16. The native source helper rejects named function keys such as `F1`; one invalid word makes the entire original spelling a Text shortcut. The actual source differential compares 4,672 cases and 149,646 exact bytes, including uppercase, minus, Unicode, whitespace, aliases and a 65,535-byte modifier chain. Prefix scanning is linear. Input text is capped at 64 KiB and sequences at 256 keys, with exact acceptance and next-bound refusal checks. Populated rows are checked for absent, empty Text, parsed Keys and full Text fallback, while the existing source presentation corpus remains exact.

Snapshot projection calls the source navigation rules for pane order and saturating indexes, empty/numeric session labels and cwd/repo tie breaking, all pane-kind labels, and detected programs. The generated program catalog retains all 154 entries. A 2,080-case source differential checks 67,842 exact bytes through real encoded/decoded snapshots and the projected fleet. Program matching preserves first candidate, 128-byte tail normalization, path boundaries, longest keys and extension fallback. Projection copies metadata without terminal planes, rejects beyond 65,536 combined nodes or 16 MiB of combined output text, and tests exact acceptance plus next-node/next-byte refusal. The process helper accepts 4,096 candidates with at most 1 MiB each; the exact next-count/next-text refusals are tested.

The private daemon check uses the native interactive stream and compiled Bend gate to exercise curated split targeting, quoted rename slots, daemon parsing of raw commands, published dynamic aliases and their inferred slots, structured/raw alias execution, and native window activation. All mutations remain outputless, so they leave command output closed. This is a controller/runtime check; it does not claim palette window rendering. Agent attention is supplied as optional metadata with source values Idle 0, Working 1, NeedsInput 2 and Failed 3. Custom agent Asset icon names are retained verbatim for future app-owned asset registration.

## Component boundary

`PaletteComponent` owns one `PaletteModel`, one text editor and a virtual list. `open` chooses places or colon command entry. `prepare` handles retained pointer and composition state before the input timeline dispatches individual `event` calls. `build` draws the source kit's input, rows, usage and footer inside a transparent modal viewport. It returns a semantic `PaletteEffect`; it does not send commands or choose a connection. The workspace adapter must capture the source connection and selection epoch before forwarding that effect.

The panel preserves the source 560px maximum width, 16px horizontal viewport margins and 12% vertical placement. List height is `min(rows * 28, clamp(viewport_height * 0.88 - 175, 40, 440))`; places always reserve the 24px usage line. A viewport layer provides hit and focus isolation while an unshifted surface retains the source placement at short heights. Initial selection is visible immediately.

The usage differential checks 2,890 source states with every row selected and with no selection: 913,540 exact bytes. Its reference applies the source preview policy to the actual `verbs::compile`, `verbs::go_to_line` and command catalog helpers. It covers readable target quoting, incomplete drafts, GUI/path previews, raw colon command usages and absent previews.

Editor changes are limited to 64 KiB after replacement and newline cleaning. Oversized insertion is refused before constructing the replacement or invoking shaping. The composition display obeys the same limit; an edit that would exceed it restores the previous text and selection. Empty clipboard paste leaves the selection intact. Undo storage is retired above 64 records or 1 MiB. A retained input scope grants one explicit layer/widget pair permission to process the previous frame's pointer state; closed, closing, mismatched and outside-modal owners are rejected.

The component has a separate semantic boundary from the workspace adapter. Fixed source icons and typed shortcuts use the native raster path. Original OpenAI and Claude SVG assets register once per component; unknown Asset metadata remains unchanged in the model and uses a generic terminal icon in the same 12px slot.

`test-palette-component` first runs the SDK's standalone retained-input probe with the default backend, then compiles the component with the native raster. Actual UI frames check interleaved insert/paste ordering, Unicode/newline cleaning, composition and commit, chip and draft transitions, exact replacement limits, oversized paste/composition rollback, post-close suffix delivery, list navigation, pointer selection before same-frame paste and outside dismissal with focus restoration. The observed guarded peak is 1,203 MiB. The component depends on the SDK's `Ui.retained_input_begin/end` layer scope API and `palette_surface_begin(..., overlay=False)` support; the default TextEdit API remains unchanged.

## Workspace routing

`PaletteRuntime` projects the attached local snapshot and dynamic aliases into one persistent component. The native Desktop and DesktopApple open keys come from the actual input router contract; the UI table wins over an armed terminal prefix. Opening queues native prefix cancellation and closes daemon command prompts or tree choosers before starting the local palette. The input timeline captures source server/client and selection epoch, preserving earlier terminal commits and post-close text/paste/key order. Physical Up/Down navigation keeps Shift/Ctrl behavior separate from text-editor movement, and forwarded terminal releases retain their original owner while the modal is open.

Semantic execution keeps the complete typed invocation and uses the existing interactive connection. Raw colon commands retain daemon-context parsing through `if-shell`; the client does not split them as shell words. Source identity gates refuse stale work, command errors preserve the connection, and outputless mutations leave the command-output view closed. Local place activation updates session/window/pane focus only after a valid landing is found. Actual detach notifications preserve metadata without silently attaching again; explicit local session selection can attach on the same connection. ServerStopping retires terminal planes and readiness watches.

`differential-palette-actions` compares 46 actual native frames / 2,779 bytes, retaining raw arguments, source spans, command-block indexes, alias and stdin fields. Its resource checks accept a complete 4 MiB frame and 4,096 arguments, then refuse the next byte or argument. `differential-palette-keys` checks 9,216 actual router cases, including all modifier combinations, press/repeat/release, overlay/capture ownership, armed-prefix precedence and native key spelling. `palette-backend-smoke` checks typed splits, quoted Unicode rename, raw execution, stale-source refusal, prefix/dialog cancellation, command-error liveness and detach/reattach against a private daemon through the compiled Bend gate.

The local workspace adapter currently supports places, curated verbs, catalog commands, aliases and raw commands. Path listing/ranking has separate source-tested services; its background job and live palette level are subsequent integration. Remote hosts, browser/editor/agent levels, persisted recents and completion services remain pending. Notifications currently use an explicit temporary status row while the canonical append/animation host is being ported. Provider OpenAI/Claude rows use the original registered SVG assets; unknown application assets retain the generic terminal icon without changing their model metadata.

`palette-workspace-smoke` runs the actual workspace and ordered input timeline against a private daemon and PTY. Its sixteen checks cover the physical open chord and associated text, earlier terminal input, exact post-close text/paste/text order, Escape followed by text and physical Enter in one batch, composition, Shift+Arrow navigation, atomic oversized PRIMARY/paste refusal, quoted Unicode and raw commands, split, row activation before a same-frame terminal suffix, output focus restoration and parked output, and native terminal search. The exact captured PTY bytes are `abTAILcd\re`; the combined build peaks at 2,495 MiB. Clipboard values belong to an isolated value adapter; the check neither reads nor prints the user's clipboard. A separate native-window build and six-frame runtime exercise the real host and renderer.

Palette dismissal restores an output owner captured as server/client/output ID, independently of the daemon's active pane. Replaced or reconnected output cannot inherit that ownership. Successful place activation chooses its explicit new input owner instead. The output regression uses the source `run-shell -t` behavior to put command output on a different pane from the active terminal; switching the active pane is not used as a substitute for parking.
