# Complete desktop key tables

`DesktopKeyTables` retains every admitted table in its actual source order, including duplicate names and complete command metadata. `RetainedKeyTables` exposes immutable shared snapshots to `StreamModel` and `AppModel`; copying an application snapshot does not copy the key tables. The GUI worker requests the actual full key subscription. The additive `native_keys=False` Hello/connect option preserves existing callers and default wire bytes.

Routing eligibility requires the full subscription, a known complete snapshot and known active-table state. Welcome invalidates old completeness and resets active state. Full events replace the vector. Patches remove every matching name, then replace the first matching table or insert using the pinned source partition-point algorithm, including its behavior on unsorted vectors. Hash notifications compare the retained hash and preserve the actual root/copy mouse bitsets. The hash uses the actual bare postcard table serialization and zero-key SipHash-1-3. Active-table updates preserve `None`/repeat normalization. Attachment changes reset active state using an immutable replacement.

Hash mismatch, malformed metadata and resource refusal make the retained state ineligible without replacing the previous immutable snapshot. The connection sends one actual `GetKeyTables` request while a refresh is pending. A successful full snapshot restores completeness; it does not invent an active table after a rejected activation update. Only actual activation or Welcome can restore unknown activation state. Handled metadata stays out of the raw event queue.

Admission remains 16 MiB encoded/retained aggregate data, 256 tables/removals, 4,096 bindings/commands, 16,384 argument/block entries, and 64 KiB text fields. Source-valid values above these limits refuse and request resynchronization. Mouse masks admit the actual 658 sparse words. Generations refuse exhaustion. These limits are adapter policy, not claims about source protocol limits. No live router hook is enabled by this prerequisite.

Run `python3 mojo/scripts/key_table_vectors.py` for 129 actual standard-library hash vectors and 282 real `ClientCore` full/patch/hash/active transitions, comparing 161,162 bytes of complete tables, mouse words and active state. Run `python3 mojo/scripts/key_table_stream.py` for private-daemon runtime bind/unbind updates, immutable sharing across 1,000 application copies, hash-mismatch and valid 257-table refusal/resync, and raw-queue exclusion. Both acquire the shared 4 GiB single-job guard. The source/probe comparison passed and scoped source clippy passed at 122 MiB. These finite checks extend the application admission boundary without adding universal Bend proof claims.
